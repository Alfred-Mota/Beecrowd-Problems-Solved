# Beecrowd Problems Solved

Este repositório reúne minhas soluções para exercícios da plataforma **Beecrowd**, com o objetivo de registrar minha evolução e compartilhar diferentes formas de resolver problemas de lógica de programação, algoritmos e banco de dados.

As soluções estão organizadas por categoria e foram desenvolvidas principalmente em **Python**, além de exercícios em **C++** e **SQL**.

## 🎯 Objetivo do repositório

Este projeto tem como principais objetivos:

* Praticar lógica de programação;
* Desenvolver habilidades na resolução de problemas;
* Aprimorar conhecimentos em algoritmos;
* Praticar diferentes linguagens de programação;
* Registrar minha evolução nos estudos;
* Compartilhar soluções que possam ajudar outros estudantes.
